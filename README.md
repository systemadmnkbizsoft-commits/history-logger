# History Logger

History Logger is a Windows desktop application for authorized browser activity monitoring and screenshot management.

## Features

- Browser history monitoring
- Session-based activity grouping
- Scheduled screenshot capture
- Screenshot gallery
- CSV export
- Browser and date filtering
- 24-hour free trial
- Product Key activation
- Configurable data retention

## Requirements

- Windows 10 or Windows 11
- Administrator permission required during installation

## Trial

New installations include a 24-hour free trial.

After the trial expires, a valid Product Key is required to continue using History Logger.
